Student Grade Calculator
Description

A simple C program that calculates the average of four subject marks and assigns a grade based on the average.
The program validates inputs to ensure marks are between 0 and 100.

Features

Input marks for 4 subjects

Input validation (0–100)

Calculates total and average

Assigns grade based on average:

A: ≥70

B: 60–69

C: 50–59

D: 40–49

F: <40
